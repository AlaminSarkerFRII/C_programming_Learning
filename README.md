# C Programming Examples

This repository is a collection of C programs demonstrating various programming concepts.


## File Descriptions

- `2.c`: Defines two functions, `add` (returns sum of two integers) and `name` (prints a name). Calls both from `main`.
- `Untitled2.c`: Works with a 2D array, prints it, calculates its sum, finds the minimum value. Also includes a `myName` function.
- `array-min.c`: Initializes a 2D array, prints it, calculates the sum of its elements, and finds the minimum element.
- `cp.c`: Prints "Hello ALamin Sarker ".
- `function.c`: Calculates factorial using recursion.
- `myName.c`: Asks the user for a number and prints "Alamin Sarker" that many times.
- `name.c`: Prints uppercase alphabets from 'A' to 'Z'.
- `nested.c`: Demonstrates nested function calls: `main` calls `name`, which calls `age`. Prints a name and age.
- `nested_Loop.c`: Uses nested for loops to print a pattern of the digit '5'.
- `pointer.c`: Demonstrates basic pointer usage.
- `recursive_function.c`: Calculates the sum of numbers up to `n` (e.g., 1 to 5) using recursion.
- `return-and-not-return-function.c`: This file is empty.
- `subFunction.c`: Demonstrates function calls: `main` calls `name`, which calls `roll`. Prints a name and a roll number.
- `sum.c`: Initializes a 2D array and finds the maximum element in it.
- `two-function-with-parameters.c`: Defines a function `sum` that calculates the sum of the square roots of two hardcoded numbers and returns the integer part of the sum.
- `two_functions_with_parametres.c`: Defines `mult` (multiplies two numbers) and `sum` (adds two hardcoded numbers), and calls them.


## How to Compile and Run

Most of these programs can be compiled using a standard C compiler like GCC. For example, to compile and run `example.c`:

```bash
gcc example.c -o example
./example
```

Replace `example.c` with the specific `.c` file you want to run. Some programs might require user input as specified in their descriptions or within the program's prompts.
